## 💳 Overview

A beginner-level ATM simulation built to practise Python input, conditions, and loops. The documented feature set includes PIN entry, a limited-attempt lock, balance checks, deposits, and withdrawals.

## ✨ Features

- PIN-based entry flow.
- Limited login attempts.
- Check balance.
- Deposit and withdraw money.
- Menu-driven terminal interaction.

## 🧰 Concepts Used

- Variables and user input
- Loops and conditional statements
- Arithmetic and validation
- Menu-based program flow

## ▶️ Run the Project

The repository's source item is named `python atm [project]`. If it contains the Python script, run it with Python; renaming the file to `atm.py` will make the run command straightforward:

```bash
python atm.py
```

## ⚠️ Scope

This is a local educational simulation, not a real ATM or banking system. Do not enter real PINs or financial details. Features such as persistent accounts, secure credential storage, and real transactions are not implied.
