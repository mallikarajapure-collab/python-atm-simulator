# 💳 ATM System in Python

A simple ATM simulation built using Python with PIN authentication and banking features.

## Features
- PIN login system
- 3 attempt security lock
- Check balance
- Deposit and withdraw money
- Menu-driven system

## Concepts Used
- Loops
- If-Else
- Variables
- Input/Output

## Run
python atm.py
